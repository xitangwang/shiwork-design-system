SHIWORK DESIGN SYSTEM

一套规范，让每个人做出同一个界面

ShiWork 外贸工作台的视觉与组件规范。沿用墨黑、朱橙和现有 Logo，在原稿基础上加大圆角、补齐组件，并新增一组 AI 组件。页面里每个示例都是真实代码，点“查看代码”即可复制。

证据优先

  • AI 说的每个事实都带来源。
  • 未核实的内容用警示色标出，不混在正文里。

人来拍板

  • 发送、发布、回传这类对外动作，一律先确认。
  • AI 只起草、建议、整理，不替人做决定。

状态可见

  • 状态分四个维度，各用固定颜色和图形。
  • 主色朱橙只给主要操作，不表达状态。

接入与文件

规范由下面这些文件组成。开发和 AI 都从这里取值，业务代码里不允许出现任何色值、字号或圆角的字面量。

文件内容谁来用
tokens.css全部设计令牌（CSS 变量），含浅色、深色两套值和图表色；由 src/tokens.src.css 生成所有人
tokens.json同一份令牌的 JSON 版本，供 Tailwind / Ant Design 主题 / 小程序等工具读取工程化
components.css组件样式，类名前缀 sw-，只引用令牌前端
charts.js零依赖图表：折线、柱形、条形、偏差、分段条、热力图、迷你走势；SW.charts.theme() 输出 ECharts / AntV 可用的主题色前端
components.js交互行为：标签页、开关、下拉、对话框、通知 SW.toast()前端
assets/icons.svg189 个图标的 SVG sprite（10 类），用 <use href="#i-名称"> 引用；分类清单见 assets/icons.json前端、设计
README.md写给 AI 和新成员的规则摘要：命名、状态、文案、禁止事项AI、新成员

基础

Logo

沿用现有 ShiWork Logo：墨黑图形 + 字标 + 朱橙句点。朱橙句点是品牌签名，页面标题句末的圆点、AI 头像右下角的圆点都从这里来。

推荐

  • 侧边栏展开时用完整 Logo，高 26px；收起时只用图形标，24px。
  • 浅色、深色两版同时放进页面，用 sw-only-light / sw-only-dark 按主题显示。
  • 四周留白不小于句点直径的 2 倍。
  • 只放在白色、--bg 或 --brand-softer 上。

避免

  • 改变句点颜色，或把整个 Logo 染成朱橙。
  • 放在照片或朱橙底上。
  • 拉伸、加描边、加阴影。

深色版由 tools/pngtool.py 从原图转换（墨色改为米白 #F2F1EE，朱橙句点不变，透明底）。正式上线前建议设计补一份 SVG 矢量版。

色彩

三种角色，互不混用：朱橙只给主要操作和选中，墨黑负责文字和 AI 标识，语义色只表达状态。卡片里的数字显示该颜色对白底的对比度。

深色主题

同一套令牌有浅色、深色两组值，组件代码完全不变。默认跟随系统；在 <html> 上设置 data-theme 可强制切换，任意容器上设置则只影响该区域。左侧导航顶部可以切换整页主题。

深色主题怎么取色

  • 不是反色：每个颜色按深色底单独取阶，并重新校验对比度。
  • 底色用暖调深灰 #0F0F0E / #1A1A19，与浅色主题的米白同一色偏。
  • “墨色元素”（用户气泡、AI 头像、提示气泡、深色按钮）反转为米白。
  • 阴影在深色下几乎看不见，浮层改为阴影 + 1px 高光描边。
  • 朱橙主色不变；浅底上的橙色文字改用更亮的 --brand-strong。

避免

  • 用纯黑 #000 做底色，或用 filter: invert() 整页反色。
  • 在组件里判断主题再写颜色；只用令牌，主题由令牌负责。
  • 图片、Logo 只放一个版本；需要两版时用 sw-only-light / sw-only-dark。
  • 危险按钮直接用 --danger 做底色；改用 --danger-solid。

接入

<html>                      <!-- 跟随系统（默认） -->
<html data-theme="light">   <!-- 强制浅色 -->
<html data-theme="dark">    <!-- 强制深色 -->
<div data-theme="dark" class="sw-root">…</div>   <!-- 只让这一块变深色 -->

<!-- 防止刷新时闪白：放在 <head> 最前面 -->
<script>
  try { const t = localStorage.getItem('sw-theme');
        if (t === 'light' || t === 'dark') document.documentElement.setAttribute('data-theme', t); } catch (e) {}
</script>

<!-- 用户切换：'auto' 删除属性回到跟随系统 -->
function setTheme(mode) {
  if (mode === 'auto') document.documentElement.removeAttribute('data-theme');
  else document.documentElement.setAttribute('data-theme', mode);
  localStorage.setItem('sw-theme', mode);
}

阴影与层级

卡片默认靠描边分隔，不加阴影。阴影只给“浮起来”的东西：下拉、弹窗、通知、浮动助手。主按钮悬停时有一道朱橙投影。

shadow-xs分段控件选中
shadow-sm卡片悬停
shadow-md下拉、通知
shadow-lg弹窗、抽屉
shadow-brand主按钮悬停

层级：吸顶 100 · 下拉 200 · 抽屉 300 · 弹窗 400 · 通知 500。不要使用这五个之外的 z-index。

图标

24px 网格、1.75 线宽、圆角端点，颜色跟随文字（currentColor）。默认显示 16px，导航 20px。AI 统一使用 ✦（sparkle / sparkles / wand），不要用机器人、大脑等图形。共 189 个，按用途分 10 类，点击图标复制引用代码。新增图标请在 tools/icons.py 里按同样规格添加。

动效

动效只用来说明“发生了什么”：出现、消失、状态切换。统一缓动 --ease，悬停 120ms，展开 200ms，抽屉 320ms。系统开启“减少动态效果”时全部关闭。

令牌时长用于
--dur-fast120ms悬停、按下、颜色变化
--dur200ms弹窗出现、开关、下拉、通知
--dur-slow320ms抽屉滑入、进度条变化

图表规则

先选图表形式，最后才选颜色。每个图表都要有图例（两个及以上系列时）、悬停提示和“数据表”视图。

推荐

  • 一个数字就能说清的，用指标卡，不画图。
  • 随时间变化用折线；比较大小用柱形或条形；一个整体拆成几部分用分段条（≤ 6 段）。
  • 柱宽不超过 24px，数据端 4px 圆角、基线端直角；折线 2px；相邻色块之间留 2px 底色间隙。
  • 网格线 1px 实线、颜色很浅；数值标签只标末端、最大值或重点系列。
  • 文字一律用文字令牌，不用系列色；系列身份靠旁边的色块。
  • 筛选器放在所有图表上方的一行里，切换时所有图表同步刷新，旧图半透明保留。

避免

  • 双 Y 轴。口径或量级不同的两个指标，拆成两个图。
  • 用箭头或漏斗把不同口径的指标连起来（如预算 → 消耗 → 询盘 → 订单）。
  • 饼图、环形图比较接近的数值；超过 7 个分类；彩虹色表示大小。
  • 在每个点上都写数字；用虚线做网格；给色块加描边分隔。
  • 把状态色（绿 / 红）当普通系列色用，或把系列色当状态用。
  • 把金额的估算值画进图里。未确认的数据不画，写在说明里。

指标卡与筛选

看板顶部用指标卡：标签、数值、相对上期的变化、近期走势。走势线用灰色，最新一段和圆点用朱橙。花费上涨用中性色，只有好坏明确的指标才用绿 / 红。

折线图

表示随时间的变化。主系列朱橙并带 10% 浅色填充，参照线（预算节奏、上期）用灰色。指针悬停时竖线吸附到最近的日期，提示框列出所有系列；聚焦后可用方向键逐日查看。

柱形图与条形图

比较大小。类别名较长或数量较多时用横向条形图；本期 / 上期对比用分组柱形图，上期用灰色；相对基准的涨跌用偏差图。

构成与分布

一个整体拆成几部分用分段条，不用饼图：段内放得下才写占比，放不下的看图例、提示和数据表。两个维度的分布用热力图，颜色深浅只表示数量。

开发检查清单

提交代码或让 AI 生成页面前，逐条对照。

  1. 只引用 tokens.css 中的变量，没有写死任何色值、字号、圆角、阴影。
  2. 只使用 sw- 组件类；需要新组件时先补进规范，再在业务里使用。
  3. 每屏最多一个 sw-btn--primary；危险按钮只出现在确认弹窗里。
  4. 状态标签按四个维度选色：数据连接、事实可信度、审核流程、对外执行；没有用朱橙表示状态。
  5. 所有 AI 产出都有 AI 标识；正文事实带引用；未核实的说法用 sw-claim 标出。
  6. 发送、发布、回传等对外动作前有确认弹窗，并列出检查项。
  7. 未确认的金额、日期写“未确认 / 待定”，没有填估算值。
  8. 所有图标按钮有 aria-label；所有表单控件有关联的 label；键盘可以操作并能看到焦点。
  9. 数字使用等宽数字，金额右对齐，日期格式统一。
  10. 加载超过 300ms 有骨架屏或加载状态；空列表有空状态说明。
  11. 在浅色和深色两种主题下都看过一遍；没有写死的白色、黑色背景；图片和 Logo 有两个版本。
  12. 图表颜色只用 --chart-* 令牌，渠道按固定配色；两个以上系列有图例；每个图表有“数据表”视图；没有双 Y 轴。
